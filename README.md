# Day book

Голосовой дневник для Android: говоришь, текст появляется сразу.
Без аккаунтов, сервера, рекламы и платных сервисов. Распознавание речи —
встроенное в Android.

**Сейчас: этап 2 из 4 — сам дневник** (версия 0.2.1).
Дальше: доводка дизайна по впечатлениям (этап 3), теги, поиск и пометка
иностранных слов (этап 4).

---

## Как получить приложение на телефон

1. Страница репозитория → **Releases** → скачать **DayBook.apk**.
2. Открыть файл, разрешить установку из этого источника → **Установить**.
3. На Samsung, если установка заблокирована: **Настройки → Безопасность и
   конфиденциальность → Автоблокировщик** — выключить на время установки.
4. Если Play Protect пишет «Неизвестный разработчик» — «Подробнее» →
   «Всё равно установить».

Если в Releases пусто — в разделе **Actions** откройте последний зелёный
запуск **Build APK** и скачайте внизу **DayBook-apk** (ZIP с APK внутри).

## Подпись (важно: от неё зависит, сохранится ли дневник при обновлении)

Все версии подписываются **одним постоянным ключом**. Тогда новая версия
ставится поверх старой и записи не пропадают.

- Ключ лежит в `signing/release.p12`, **зашифрован паролем**. Без пароля он
  бесполезен, поэтому хранить его в репозитории безопасно.
- Пароль знает только владелец. Он хранится в секрете GitHub
  `SIGNING_PASSWORD` и в вашем менеджере паролей.
- **Если потерять пароль**, обновления перестанут ставиться поверх старой
  версии. Придётся сохранить копию дневника, удалить приложение, поставить
  новое и восстановить копию.

Настройка (один раз):
1. Придумайте пароль: 24+ символа, **только латинские буквы и цифры**.
   Сохраните его в менеджер паролей.
2. Репозиторий → **Settings → Secrets and variables → Actions →
   New repository secret**. Имя: `SIGNING_PASSWORD`, значение: пароль.
3. **Actions → Create signing key (one-time) → Run workflow**.
   Через минуту в репозитории появится `signing/release.p12`.

## Как пользоваться

- **Записать:** выберите язык внизу (RU, UK, EN, DE) и нажмите оранжевую
  кнопку с микрофоном. Говорите сколько угодно, паузы не обрывают запись.
  Светлые слова ещё уточняются, обычные — уже сохранены. Остановить —
  та же кнопка (квадрат). Одно нажатие — одна запись; дата и время ставятся сами.
- **Языки:** русский, английский и немецкий распознаются прямо на телефоне,
  без интернета. Украинский — только через интернет (службой Google).
  Если сказать целую фразу на другом языке, дневник попробует переключиться
  сам (выключается в настройках).
- **Знаки препинания:** ставятся сами. Можно сказать последним словом перед
  паузой «запятая», «точка», «вопросительный знак» (укр. «кома», «крапка»,
  «знак питання»; англ. «comma», «period»; нем. «Komma», «Punkt»).
  После длинной паузы фраза заканчивается точкой.
- **Дописать за прошлый день:** раскройте этот день и нажмите «+ Дописать
  за этот день», или нажмите «+» вверху и выберите «Вчера», «Позавчера» или
  «Другой день». Над кнопками появится «Запись за …» — микрофон пишет в этот
  день (время — текущее, его можно поправить). Крестик — снова «сегодня».
  Если свернуть приложение, дневник сам вернётся к «сегодня».
- **Лента:** сверху новые дни. Нажмите на день — он раскроется,
  ещё раз — свернётся.
- **Править:** нажмите на запись. Можно исправить текст, время и дату
  (нажмите на время вверху) или удалить запись.
- **Код на вход:** Настройки → «Включить код» (4 цифры), можно открывать
  отпечатком. Если забыть код, восстановить его нельзя — делайте копию.
- **Резервная копия:** Настройки → «Сохранить копию» — весь дневник одним
  файлом. Сохраните его, например, в Google Диск. «Восстановить из копии»
  добавляет записи из файла, не удаляя текущие.
- Пока идёт запись, экран не гаснет. Если свернуть приложение, запись
  заканчивается, всё сказанное уже сохранено.
