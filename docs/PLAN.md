# План и решения

Документ для продолжения работы в новой сессии. Владелец работает только
с телефона, код знает поверхностно.

## Правила работы
- Отвечать по-русски, простыми словами, термины объяснять.
- Работать этапами: что сделано → как проверить на телефоне → что дальше.
  Следующий этап — только после «ок» владельца.
- Перед любым действием, которое стоит денег или требует регистрации, — стоп и вопрос.
- Каждая версия — APK через GitHub Releases. Подпись всегда одна
  (signing/release.p12 + секрет SIGNING_PASSWORD), иначе обновление сотрёт дневник.
- Не давать список вариантов — рекомендовать один и объяснить почему.
- Это отдельное приложение, ни с какими другими проектами владельца не связано.

## Телефон
Samsung Galaxy S21 Ultra, One UI 7 (Android 15). Точную модель покажет экран этапа 1.

## Что делает приложение (задание)
- Микрофон: говоришь сколько угодно, паузы не обрывают, текст сразу на экране.
- Распознавание — встроенное в Android, бесплатное.
- Языки кнопками RU, UK, EN, DE, последний запоминается. Одна запись — один язык.
- Текст правится во время диктовки; новые слова идут в конец.
- Каждый распознанный кусок сразу сохраняется; экран во время диктовки не гаснет.
- Одно нажатие микрофона — одна запись; дата и время ставятся сами, их можно править.
- День — страница с записями по времени; дни листаются свайпом; нажатие на
  дату открывает месяц с отметками дней, где есть записи.
- Теги одним нажатием из своего набора; поиск по тексту и тегам.
- Резервная копия: автокопия Android + кнопка «Сохранить копию» одним файлом
  с восстановлением.
- Пунктуация: автоматическая там, где работает (Android 13+, форматирование);
  иначе — голосовые «точка», «запятая» и точка с заглавной после длинной паузы.
- Иностранные слова в русской записи: нажатием помечаются, запоминаются и везде
  показываются чуть светлее.
- Дизайн: «страница, написанная синей шариковой ручкой». Один цвет чернил на
  холодном белом; тёмная тема — светлые чернила на глубоком синем. Контраст
  ≥ 4.5:1. Шрифт Literata (встроенный; проверить і ї є ґ). Без карточек, теней,
  стандартного Material, надписей заглавными и эмодзи. Вверху день недели и
  крупная дата; слева время, справа текст с широкими полями; внизу один круглый
  микрофон и языки рядом. Слова появляются бледными и темнеют после подтверждения
  («высыхающие чернила»).

- Телефон: samsung SM-G998B (p3s), Android 15, API 35.
- Службы: Android System Intelligence (com.google.android.as), «Распознавание
  и синтез речи» (com.google.android.tts — по умолчанию), Bixby Recognition
  Service (Samsung), Claude (com.anthropic.claude — не используем).
- Системный «на телефоне» есть. RU — офлайн-пакет скачан; UK — НЕ поддерживается
  на телефоне (только онлайн через Google → текст уходит в Google); EN, DE —
  офлайн можно скачать.
- Обе службы Google назывались «Google» — в v0.1.1 ASI подписана «Google ASI».
- Проверка 1 (На телефоне, RU, режим A, пунктуация): 112 с, 20 кусков,
  31 перезапуск (≈ каждые 3,6 с) → режим A на этом телефоне НЕ держит сеанс.
  Разрыв при перезапуске 318 мс в среднем, до 570 мс (слова на стыках могут
  теряться). Ошибки: «ничего не распознано» ×6, «занят» ×3, «служба

  каждого куска («Если я говорю. То это не значит») — в этапе 2 склеивать
  куски: короткая пауза → без точки и со строчной. Уверенность по словам:
  все 92 «неизвестна» → для пометки иностранных слов не годится (как и решено).
- v0.1.2: добавлен режим C «свой микрофон» (EXTRA_AUDIO_SOURCE + труба,
  AudioRecord 16 кГц моно) — должен убрать перезапуски/разрывы/писк.
  Также в v0.1.2: флажок «смена языка» (Android 14+: EXTRA_ENABLE_LANGUAGE_SWITCH
  + DETECTION, языки ru/uk/en/de; отчёт показывает услышанные языки и итоги
  переключений).
- Писка при перезапусках владелец НЕ слышал (режим A, «На телефоне»).
- Владелец: «слова, сказанные на другом языке, переименовало по-другому» —
  русский распознаватель превращает иностранные слова в похожие русские.
  Проверяем «смену языка»; честно: одиночное слово внутри русской фразы
  вряд ли переключит язык — тогда остаётся правка вручную.
- Проверка 2 (v0.1.2, На телефоне, RU, режим C, пунктуация): 80 с, 9 кусков,
  0 перезапусков, 0 ошибок, остановка кнопкой. РЕЖИМ C РАБОТАЕТ → запись в
  дневнике делаем через «свой микрофон» (EXTRA_AUDIO_SOURCE + труба), на
  телефоне, офлайн. Пунктуация есть, но точек меньше, а заглавные иногда
  посреди фразы («…может сказать Вот так А как…») → в этапе 2 при склейке
  кусков приводить регистр: заглавная только после . ! ? (и в начале записи).
  EN и DE офлайн-пакеты владелец скачал (RU, EN, DE — офлайн; UK — нет).
- Проверка 3 (v0.1.2, На телефоне, RU, C, «смена языка» QUICK_RESPONSE, языки
  ru/uk/en/de): 141 с, 27 кусков, 0 перезапусков. Целые фразы EN и DE
  распознаны на своём языке (удачных переключений 46). НО быстрый режим даёт
  ложные переключения: русская речь иногда → английский мусор («Tuck the wiper
  to just», «Very dominant»). UK: «нет пакета языка» ×373 → украинская речь

  РЕШЕНИЕ для этапа 2: смена языка в режиме LANGUAGE_SWITCH_HIGH_PRECISION,
  разрешённые языки — только те, что есть офлайн (сейчас ru, en, de), плюс
  переключатель в настройках. Одиночные иностранные слова — правка вручную.
- Проверка 4 (v0.1.2, «Google» = com.google.android.tts, UK, C, онлайн):
  78 с, 13 кусков, 0 перезапусков → режим C работает и с онлайн-службой.
  Украинский распознаётся хорошо; онлайн-модель сама пишет вставки на других
  языках (рус. фраза — по-русски, «You never know» — по-английски). Знаков
  препинания для UK НЕТ (только заглавные).

## ИТОГ ЭТАПА 1 (решения для этапа 2)
- Запись: режим C («свой микрофон»: AudioRecord 16 кГц моно → труба →
  EXTRA_AUDIO_SOURCE, EXTRA_SEGMENTED_SESSION = EXTRA_AUDIO_SOURCE). Нет
  перезапусков, разрывов, писка. Звук нигде не сохраняется.
- RU, EN, DE — «На телефоне» (createOnDeviceSpeechRecognizer), офлайн, приватно.
  Если пакета языка нет — кнопка «скачать» (triggerModelDownload).
- UK — только онлайн через службу com.google.android.tts (на телефоне UK нет).
  Честно предупредить в приложении один раз: «украинский распознаётся через
  интернет (Google)».
- Пунктуация: RU/EN/DE — от распознавателя (EXTRA_ENABLE_FORMATTING), но
  склейка кусков: заглавная только после . ! ? и в начале записи. UK — своя:
  длинная пауза между кусками → точка и заглавная; голосовые «крапка», «кома»
  (последним словом перед паузой).
- Смена языка (офлайн): HIGH_PRECISION, только языки с офлайн-пакетом,
  выключатель в настройках. Одиночные иностранные слова — правка нажатием.
- Уверенность по словам не приходит → не используем.

## Код на вход (просьба владельца 10.11.2026)
Не шифрование — «замок от любопытных друзей».
- В настройках: включить код из 4 цифр (по умолчанию выключен). Хранить
  хэш кода, не сам код.
- Спрашивать при запуске и после возврата, если приложение было в фоне
  дольше 1 минуты.
- Открытие отпечатком (androidx.biometric, BIOMETRIC_STRONG|WEAK) — по
  желанию, предлагать при включении кода.
- 5 неверных попыток → пауза 30 с.
- Скрыть картинку в «недавних приложениях»: setRecentsScreenshotEnabled(false)
  (API 33, есть при minSdk 33) — иначе текст виден без кода. Скриншоты
  внутри приложения НЕ запрещать (без FLAG_SECURE).
- Забыл код и отпечаток не работает → восстановления нет (сервера нет);
  спасает только резервная копия → кнопку «Сохранить копию» перенести
  в этап 2.

## Этапы
1. **Проверка распознавания** — СДЕЛАНО. Версия v0.1.0 выпущена в Releases,
   подписана постоянным ключом; ждёт проверки на телефоне. Итог этапа — таблица «что работает на каждом языке»
   по отчёту, который владелец скопирует из приложения.
2. Дневник: запись, правка, лента дней (раскрытие дня), сохранение — в утверждённом дизайне.
   Плюс код на вход (4 цифры + отпечаток) и кнопка «Сохранить копию»/восстановление.
3. Дизайн — макеты утверждены заранее (см. раздел «Дизайн»), этап 2 сразу
   строится в нём; этап 3 — только доводка по впечатлениям с телефона.
4. Теги, поиск, пометка иностранных слов (резервная копия перенесена в этап 2).

## Принятые решения
- Kotlin + Jetpack Compose (только foundation, свой внешний вид, без Material).
  minSdk 33. Хранение (этап 2): Room/SQLite с полнотекстовым поиском (FTS).
- Сборка: GitHub Actions (.github/workflows/build.yml). Релиз — по тегу `v*`
  или ручному запуску с полем release_tag. APK: DayBook.apk.
- Подпись: свой ключ, создаётся один раз workflow «Create signing key (one-time)»
  после того, как владелец добавит секрет SIGNING_PASSWORD (24+ латинских букв
  и цифр). НАСТРОЕНО 9.11.2026: ключ в signing/release.p12, v0.1.0 подписана им
  (сборка сверила отпечаток). Тестовую сборку с отладочным ключом владелец не ставил.
- Нет разрешения INTERNET (сборка проверяет APK). Единственное разрешение — микрофон.
- Режим «на устройстве» — основной (приватность); онлайн — только для языка без
  офлайн-пакета.
- Длинный сеанс: EXTRA_SEGMENTED_SESSION (API 33). Проверяем варианты A (int)
  и B (long) для EXTRA_SPEECH_INPUT_MINIMUM_LENGTH_MILLIS. Если не работает —
  перезапуск распознавателя (возможны писк и разрыв).
- С EXTRA_ENABLE_FORMATTING служба отдаёт 2 варианта: [0] с пунктуацией, [1] без.
- Уверенность по словам: API 34 (RecognitionPart, RECOGNITION_PARTS). Автоматически
  иностранные слова НЕ помечать — только подсказка, если данные окажутся полезными.
- Голосовая «точка» превращается в знак только последним словом перед паузой
  (иначе «точка зрения» ломается).
- Правка во время диктовки: подтверждённый текст правится, бледный хвост — нет.
- Запись идёт только при открытом приложении; ушли с экрана — запись завершается,
  всё сказанное сохранено.
- Свайп листает только дни с записями (и сегодняшний); к любой дате — через календарь.
- Резервная копия: главная — файл (JSON) через системное окно сохранения;
  автокопия Android — дополнительная.
- Цвета: чернила с контрастом около 9:1, чтобы «светлее» для иностранных слов
  тоже держало ≥ 4.5:1.
