# План и решения

Документ для продолжения работы в новой сессии. Владелец работает только
с телефона, код знает поверхностно.

## Правила работы
- Отвечать по-русски, простыми словами, термины объяснять.
- Работать этапами: что сделано → как проверить на телефоне → что дальше.
  Следующий этап — только после «ок» владельца.
- Перед любым действием, которое стоит денег или требует регистрации, — стоп и вопрос.
- Каждая версия — APK через GitHub Releases. Подпись всегда одна
  (signing/release.p12 + секрет SIGNING_PASSWORD), иначе обновление сотрёт дневник.
- Не давать список вариантов — рекомендовать один и объяснить почему.
- Это отдельное приложение, ни с какими другими проектами владельца не связано.

## Телефон
Samsung Galaxy S21 Ultra, One UI 7 (Android 15). Точную модель покажет экран этапа 1.

## Что делает приложение (задание)
- Микрофон: говоришь сколько угодно, паузы не обрывают, текст сразу на экране.
- Распознавание — встроенное в Android, бесплатное.
- Языки кнопками RU, UK, EN, DE, последний запоминается. Одна запись — один язык.
- Текст правится во время диктовки; новые слова идут в конец.
- Каждый распознанный кусок сразу сохраняется; экран во время диктовки не гаснет.
- Одно нажатие микрофона — одна запись; дата и время ставятся сами, их можно править.
- День — страница с записями по времени; дни листаются свайпом; нажатие на
  дату открывает месяц с отметками дней, где есть записи.
- Теги одним нажатием из своего набора; поиск по тексту и тегам.
- Резервная копия: автокопия Android + кнопка «Сохранить копию» одним файлом
  с восстановлением.
- Пунктуация: автоматическая там, где работает (Android 13+, форматирование);
  иначе — голосовые «точка», «запятая» и точка с заглавной после длинной паузы.
- Иностранные слова в русской записи: нажатием помечаются, запоминаются и везде
  показываются чуть светлее.
- Дизайн: «страница, написанная синей шариковой ручкой». Один цвет чернил на
  холодном белом; тёмная тема — светлые чернила на глубоком синем. Контраст
  ≥ 4.5:1. Шрифт Literata (встроенный; проверить і ї є ґ). Без карточек, теней,
  стандартного Material, надписей заглавными и эмодзи. Вверху день недели и
  крупная дата; слева время, справа текст с широкими полями; внизу один круглый
  микрофон и языки рядом. Слова появляются бледными и темнеют после подтверждения
  («высыхающие чернила»).

## Этапы
1. **Проверка распознавания** — СДЕЛАНО в коде (v0.1.0), ждёт первой сборки
   и проверки на телефоне. Итог этапа — таблица «что работает на каждом языке»
   по отчёту, который владелец скопирует из приложения.
2. Дневник: запись, правка, страницы дней, сохранение.
3. Дизайн.
4. Теги, поиск, пометка иностранных слов, резервная копия.

## Принятые решения
- Kotlin + Jetpack Compose (только foundation, свой внешний вид, без Material).
  minSdk 33. Хранение (этап 2): Room/SQLite с полнотекстовым поиском (FTS).
- Сборка: GitHub Actions (.github/workflows/build.yml). Релиз — по тегу `v*`
  или ручному запуску с полем release_tag. APK: DayBook.apk.
- Подпись: свой ключ, создаётся один раз workflow «Create signing key (one-time)»
  после того, как владелец добавит секрет SIGNING_PASSWORD (24+ латинских букв
  и цифр). ЕЩЁ НЕ НАСТРОЕНО.
- Нет разрешения INTERNET (сборка проверяет APK). Единственное разрешение — микрофон.
- Режим «на устройстве» — основной (приватность); онлайн — только для языка без
  офлайн-пакета.
- Длинный сеанс: EXTRA_SEGMENTED_SESSION (API 33). Проверяем варианты A (int)
  и B (long) для EXTRA_SPEECH_INPUT_MINIMUM_LENGTH_MILLIS. Если не работает —
  перезапуск распознавателя (возможны писк и разрыв).
- С EXTRA_ENABLE_FORMATTING служба отдаёт 2 варианта: [0] с пунктуацией, [1] без.
- Уверенность по словам: API 34 (RecognitionPart, RECOGNITION_PARTS). Автоматически
  иностранные слова НЕ помечать — только подсказка, если данные окажутся полезными.
- Голосовая «точка» превращается в знак только последним словом перед паузой
  (иначе «точка зрения» ломается).
- Правка во время диктовки: подтверждённый текст правится, бледный хвост — нет.
- Запись идёт только при открытом приложении; ушли с экрана — запись завершается,
  всё сказанное сохранено.
- Свайп листает только дни с записями (и сегодняшний); к любой дате — через календарь.
- Резервная копия: главная — файл (JSON) через системное окно сохранения;
  автокопия Android — дополнительная.
- Цвета: чернила с контрастом около 9:1, чтобы «светлее» для иностранных слов
  тоже держало ≥ 4.5:1.
